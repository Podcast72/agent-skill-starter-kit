# Create Your Own Skill

This is the short extended guide for turning this repository method into your own local skill.

Start with:

- [START_HERE.md](../START_HERE.md)
- [Skill configuration template](../templates/skill-config-template.md)
- [Create my skill prompt](../prompts/create-my-skill-from-config.md)

## Flow

1. Open `START_HERE.md`.
2. Fill in `templates/skill-config-template.md`.
3. Open `prompts/create-my-skill-from-config.md`.
4. Paste the prompt into your coding agent together with your filled configuration.
5. Let the agent generate a custom skill folder.
6. Review the generated files before using them.
7. Test the skill on one small local task.

## What to keep in mind

- Change the skill name, activation line, scope, and preferences first.
- Keep scripts, templates, and checks only if they solve a repeated need.
- Treat passive review logging as optional and manual.
- Remove anything you do not need before using the skill on real work.

This repository gives you a method and a starting structure. It does not remove the need for review, testing, or technical judgment.

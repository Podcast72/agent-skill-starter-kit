# Experimental Passive Skill

Experimental Passive Skill is a neutral example of a skill pattern that can record minimal metadata for manual review.

It can record:
- event type;
- task type;
- selected mode;
- status;
- timestamp.

It does not self-improve automatically.
It does not modify itself.
It does not change configuration.
It does not install hooks.
It does not store full prompts.
It does not store secrets.

The goal is not automatic self-improvement. The goal is to make future manual review easier.

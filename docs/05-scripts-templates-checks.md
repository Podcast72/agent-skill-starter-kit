# Scripts, Templates, Checks

Scripts are useful when an operation is mechanical, repeated or easy to validate.
Scripts are not useful when the task mainly depends on interpretation, context or tradeoffs.

Templates reduce output variation by giving the agent a known structure to follow.
Checks reduce simple mistakes by validating minimum requirements before a result is accepted.

Use scripts for repeatable operations.
Use the agent for reasoning, interpretation and decisions.

Scripts should support judgment, not replace it.

# How To Adapt

1. Pick a recurring task.
2. Decide what the agent should always do the same way.
3. Decide what should remain agent judgment.
4. Create `SKILL.md`.
5. Add scripts only for repeatable tasks.
6. Add templates for recurring outputs.
7. Add checks for minimum validation.
8. Add hooks only if needed.
9. Test on a safe example.
10. Keep improving manually.

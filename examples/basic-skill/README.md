# Basic Skill Example

## What it does

This is the smallest copyable example in the repository. It shows the core method without optional scripts, templates, or checks.

## What to change

- Rename the folder.
- Change the skill name and description in `SKILL.md`.
- Change the activation line.
- Adjust scope, rules, and final report fields for your own workflow.

## What to keep

- The small `SKILL.md` structure.
- The scope-first workflow.
- The stop rules.
- The short final report pattern.

## What it must not do

- It must not use network access by default.
- It must not use destructive commands by default.
- It must not depend on hidden scripts or private configuration.

## Optional files

This example intentionally has no scripts, no checks, and no templates. Add them only after a real repeated need appears.

## How to test it on a small task

1. Use it for one small documentation or local review task.
2. Confirm that the scope remains narrow.
3. Confirm that the final report is short and clear.

# Experimental Passive Skill

## Activation

Use this skill when you want a local skill example with optional minimal usage logging for manual review.

## Rules

- Experimental.
- Passive.
- No auto-upgrade.
- No self-modification.
- No global configuration changes.
- No automatic hook installation.
- No full prompt logging.
- No secret logging.
- No personal data logging.
- Usage logging only when explicitly allowed.
- Manual review only.

## Final Report Format

```text
MODE:
TASK:
LOGGING USED:
FILES CHANGED:
VALIDATION:
LIMITS:
STATUS:
```

# Create Skill Family

Use this prompt to create a small family of related local agent skills.

```text
Create a small family of related local agent skills with these parts:

1. Main skill
2. Rapid or simple skill
3. Docs or research skill
4. Optional experimental passive skill

Requirements:
- Keep the naming generic.
- Write everything in English.
- Use frontmatter with name and description for every skill.
- Keep shared rules consistent across the family.
- Let each skill focus on one clear task type.
- Make the experimental passive skill strictly passive and manual-review only.
- Do not include private paths, personal data, secrets or proprietary references.
```

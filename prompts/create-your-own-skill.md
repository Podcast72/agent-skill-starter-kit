# Create Your Own Skill

Use this prompt to create one custom local agent skill.

```text
Create a reusable local agent skill with the following placeholders:

SKILL NAME: [SKILL_NAME]
MAIN PURPOSE: [MAIN_PURPOSE]
ACTIVATION PHRASE: [ACTIVATION_PHRASE]
SAFE RULES: [SAFE_RULES]
BUILD RULES: [BUILD_RULES]
POWER RULES: [POWER_RULES]
FINAL REPORT FORMAT: [FINAL_REPORT_FORMAT]

Requirements:
- Write everything in English.
- Keep the structure simple and reusable.
- Use frontmatter with name and description.
- Explain the activation line, scope and rules clearly.
- Keep destructive actions out of default behavior.
- Add scripts only if they support repeatable tasks.
```

# Add Scripts To Skill

Use this prompt to extend an existing skill with helper scripts.

```text
Add small helper scripts to an existing local agent skill.

Include:
- mode detection
- scope guard
- report check
- validation script

Requirements:
- Use standard library tools only where possible.
- Keep scripts small and readable.
- Make scripts helpers, not replacements for judgment.
- Add a template for the final report.
- Explain when each script should be used.
- Avoid destructive behavior and global changes.
```

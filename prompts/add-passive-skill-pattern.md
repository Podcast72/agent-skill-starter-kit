# Add Passive Skill Pattern

Use this prompt to add an experimental passive usage-log pattern to a skill.

```text
Add an experimental passive usage-log pattern to an existing local agent skill.

Requirements:
- Record minimal metadata only.
- Do not store full prompt text.
- Do not store secrets.
- Do not auto-upgrade.
- Do not modify the skill automatically.
- Keep it for manual review only.
- Explain the logging limits clearly in the skill documentation.
```
